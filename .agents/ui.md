# UI, Figma e assets

- A implementação deve traduzir o layout e a identidade visual definidos no Figma do projeto.
- Para tarefas design-to-code, consulte o nó específico do Figma antes de escrever código e trate o código retornado como referência, adaptando-o à estrutura real do projeto.
- Preserve proporções, espaçamentos, tipografia, posicionamento e cores do design nas larguras de referência.
- Use os assets exportados do Figma. Para assets em `public`, referencie caminhos iniciados por `/`.
- Não substitua imagens, ícones ou grafismos por aproximações sem necessidade.
- Use `lucide-react` para ícones quando o glyph existente corresponder; não crie SVG manualmente nesses casos.
- Mantenha textos em português do Brasil e use HTML semântico, navegação por teclado e nomes acessíveis para controles interativos.
